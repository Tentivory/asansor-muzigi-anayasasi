# Asansör Müziği Anayasası

Bu belge, insanlığın asansörde geçirdiği o kısa ve utangaç saniyeleri **uluslararası hukuk** seviyesine çıkarmak için yazılmıştır.

Proje, katlar arası geçişi bir rejim değil, bir **ritüel** olarak kabul eder. Kapı kapanır. Müzik başlar. Kimse kimseye bakmaz. Anayasa işte tam orada yürürlüğe girer.

## Ne işe yarar?

Hiçbir şeye. Ama çalışır.

```bash
python3 anayasa.py
```

Program şunları yapar:

1. Rastgele bir kat seçer.
2. O kata uygun anayasa maddesi yazar.
3. Asansör müziğini kelimelerle besteler.
4. Kuyrukta duranlara resmî bir teşekkür metni basar.

## Madde 1

Asansörde öksürmek, ancak düşük sesle ve pişman bir yüz ifadesiyle serbesttir.

## Madde 2

Aynı kata giden iki yabancı, zemin katta tekrar karşılaşırsa birbirini tanımıyormuş gibi davranmak zorundadır.

## Madde 3

Müzik bitmeden kapıya basmak, anayasal suçtur. Cezası bir tur daha dinlemektir.

## Kurulum

Python 3 yeter. Bağımlılık yok. Çünkü bağımlılık, asansörün kapısını açık tutmak gibidir: nezaketsiz.
